# Subsequent-pass convergence

Apply this only when the plan contains review-history notes, previous-iteration sections, accepted-update markers, sibling
plans referring to prior review rounds, or the user says this is iteration N.

1. Preserve the prior disposition of a finding whose underlying section is materially unchanged from a competent prior
   review. Reopen it only when the governing rule or evidence changed.
2. Focus first on issues introduced by recent edits.
3. Apply the main skill's Blocking threshold and severity definition unchanged as obvious problems disappear.
4. Bias toward `READY FOR HANDOFF` when the remaining choice is another polish round versus shipping.

On a first pass, review the plan as written without anchoring to presumed prior acceptance.
