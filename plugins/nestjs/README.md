# NestJS Plugin

NestJS backend architecture, security, data, job, and testing guidance for agent-assisted projects.

- Start with [conduct/overview.md](./conduct/overview.md) and load only the documents routed by the target.
- Use [architect](./skills/architect/SKILL.md) for feature design, and the [fast](./skills/reviewer-fast/SKILL.md), [deep](./skills/reviewer-deep/SKILL.md), and [business-logic](./skills/reviewer-business-logic/SKILL.md) reviewers for the matching review scope.
- Use [tester](./skills/tester/SKILL.md) after implementation and non-test checks are complete.
- Follow the consuming project's own commands, schema library, database adapter, and test policy.
